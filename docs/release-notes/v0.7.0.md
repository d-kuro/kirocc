# Release v0.7.0

## New Features

### Claude Opus 5 Support (#85)

Adds `claude-opus-5` to the model mapping table as an always-1M SKU, with a first-class `claude-opus-5[1m]` alias and the five-value effort enum (`low` / `medium` / `high` / `xhigh` / `max`).

## Bug Fixes

- Wrap non-object tool schemas in an object envelope so Kiro no longer rejects them with `TOOL_SCHEMA_INVALID` — fixes 502 errors when Claude Code uses WebSearch and other tools with non-object root schemas (#93)
- Fall back to alternative usage sources when Kiro metadata has no token counts, instead of reporting zero usage (#84)

## Documentation

- Document Kiro API key authentication (`KIRO_API_KEY` / `KIRO_API_REGION`) for headless environments (#91)

## Dependency Updates

- Update opentelemetry-go monorepo to v1.45.0 (#95)
- Bump google.golang.org/grpc from 1.81.1 to 1.82.1 (#82)
- Update modernc.org/sqlite to v1.55.0 (#80)
- Update github.com/lmittmann/tint to v1.2.0 (#79)
- Update golang.org/x/sync to v0.22.0 (#77)
