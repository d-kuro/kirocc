# Release v0.15.0

## New Features

### Claude Sonnet 5.5 (#166)

`claude-sonnet-5-5` and `claude-sonnet-5-5[1m]` are now built-in mappings to the `claude-sonnet-5.5` Kiro SKU, and the Claude Code model picker lists "Sonnet 5.5 (1M context)". Sonnet 5.5 is an always-1M model; the `[1m]` suffix only advertises the 1M window and does not enable thinking. Effort supports the full `low` / `medium` / `high` / `xhigh` / `max` enum. Before this, sessions without catalog discovery (e.g. API-key auth) passed the ID through with a 200k window and dropped the effort.
